# Как залить (5 минут)

Всё содержимое этой папки идёт в корень репозитория **korshi-site** — как есть, без переименований и без вложенных папок.

1. GitHub → репозиторий **korshi-site** → **Add file → Upload files**.
2. Выделите все 7 файлов из этой папки (кроме этого README, он не нужен на сайте) и перетащите в окно.
3. **Commit changes**. Vercel переложит сайт сам за ~1 минуту.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | сам сайт |
| `og-cover.png` | обложка 1200×630 для WhatsApp / Telegram / Instagram |
| `favicon.png` | иконка во вкладке браузера |
| `apple-touch-icon.png` | иконка для домашнего экрана телефона |
| `panel-x9k4q.html` | админ-панель заявок |
| `robots.txt` | пускает Google на сайт, закрывает админку от индексации |
| `sitemap.xml` | карта сайта для Google |

## Админка

Адрес: `korshi-site.vercel.app/panel-x9k4q.html` — имя файла работает как пароль, поэтому не публикуйте ссылку.
Сменить «пароль»: переименуйте файл на GitHub и поменяйте ту же строку в `robots.txt`.
На телефоне: откройте ссылку → «Поделиться» / «⋮» → «На экран Домой».

## После деплоя

- Проверьте обложку: [Facebook debugger](https://developers.facebook.com/tools/debug/) — вставьте адрес сайта, нажмите Scrape Again. Так же обновится кэш в WhatsApp.
- Для Google: [Search Console](https://search.google.com/search-console) → добавьте домен → отправьте `sitemap.xml`. Индексация занимает несколько дней.
- Свой домен (korshi.app): Vercel → Settings → Domains. После смены домена скажите мне — поменяю адреса в мета-тегах, иначе обложка в соцсетях перестанет подтягиваться.
